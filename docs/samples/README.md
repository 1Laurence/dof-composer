## 文件

| 文件 | 内容 |

## 复现方式

```bash
dof-composer docs/samples/cat_park.jpg -o out
```

默认参数：`--encoder vitl`、`--blur-sigma 12`、`--depth-input-size 518`。

## 为什么选这张

客观依据是"背景细节量"和"主体保持度"两项指标。
用拉普拉斯方差在 alpha 遮罩内精确统计：

| 指标 | 室内猫（备选） | 公园猫（采用） |
|---|---|---|
| 主体内部锐利度保持 | 96.2% | **96.9%** |
| 背景锐利度 | 17.0 | **44.6** |
| 虚化后背景 | 2.9（降 83.0%） | 9.3（降 79.1%） |

决定性差异在**背景原始锐利度**：公园图有 44.6 的丰富纹理（树叶、草地、远景小路），
虚化后掉到 9.3，视觉反差极强；室内图背景本来就只有 17.0，
虚化到 2.9 肉眼几乎看不出变化。

另外三点：

- **纵深层次长**：从近处石板路 → 猫 → 灌木 → 树林 → 远处小路，
  深度图能体现完整的距离梯度
- **有细结构**：猫的胡须、耳毛、白胸毛可以验证算法不会把该锐利的地方糊掉
- **原图接近全焦**：虽然背景本身略虚（手机或 AI 生成图的常态），
  但仍保留了足够纹理，能看出算法做了什么

## 自己准备样例图的建议

手机拍一张即可，注意：

1. **主体明确**放在画面中偏前位置
2. **背景有纵深**，比如走廊、街道、摆满东西的桌面
3. **背景必须有细节**（这点最容易被忽略）：树叶、砖墙、书架、栏杆都行。
   纯色墙面或天空虚化后看不出变化，演示效果会打折
4. **不要开人像模式**，需要全焦原图，否则背景本来就在虚化，
   看不出算法做了什么
5. 分辨率 1500~2000px 宽足够，太大只会让仓库变胖

想自己量化筛选，可以跑这段：

```python
import cv2
gray = cv2.cvtColor(cv2.imread("候选图.jpg"), cv2.COLOR_BGR2GRAY)
print("锐利度", cv2.Laplacian(gray, cv2.CV_64F).var())
```
